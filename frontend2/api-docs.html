Gari API-as-a-Service (v1)

v1.0.0 Production RESTful AI Engine

Tài liệu kỹ thuật tích hợp động cơ nhận diện bệnh lá cây Gari vào trạm quan trắc IoT, máy bay không người lái (Drone) và phần mềm quản lý trang trại ERP.

Quản lý API Key tổ chức

1. Xác thực bằng API Key (Authentication)

Mọi yêu cầu gửi đến API suy luận v1 bắt buộc phải kèm theo khóa API hợp lệ của tổ chức (gói Team hoặc Enterprise). Bạn có thể truyền khóa qua một trong hai cách:

  • Cách 1 (Khuyên dùng): Sử dụng Header HTTP X-Gari-API-Key: gari_live_xxxxxxxxxxxxxxxxxxxx
  • Cách 2: Sử dụng Header Authorization Authorization: Bearer gari_live_xxxxxxxxxxxxxxxxxxxx
POST /api/v1/diagnose

Kiểm định chất lượng lá cây (Leaf Validation Gate) -> Nhận diện loài cây -> Phân loại bệnh học và khoanh vùng tổn thương (Grad-CAM). Tự động kiểm tra hạn ngạch tổ chức và bảo vệ an toàn nông học.

Tham số Request (multipart/form-data):

Trường (Field) Kiểu dữ liệu Bắt buộc Mô tả
image File (Binary) Bắt buộc Ảnh chụp lá cây (JPEG, PNG, WEBP), tối đa 15MB.
mode String Tùy chọn auto_standard (chuẩn) hoặc manual hoặc auto_pro (gói Team/Enterprise).
crop String Tùy chọn Chỉ định loại cây khi chạy chế độ manual (vd: Tomato, Pepper, Rice).
notes String Tùy chọn Ghi chú lô canh tác hoặc trạm quan trắc.

Ví dụ tích hợp Python (Requests):

import requests

url = "http://localhost:8000/api/v1/diagnose"
headers = {
    "X-Gari-API-Key": "gari_live_your_org_api_key_here"
}

with open("leaf_sample.jpg", "rb") as f:
    files = {"image": ("leaf.jpg", f, "image/jpeg")}
    data = {"mode": "auto_standard"}
    response = requests.post(url, headers=headers, files=files, data=data)

result = response.json()
print("Kết quả:", result["diagnosis"]["name_vi"], f"({result['diagnosis']['confidence_score'] * 100:.1f}%)")
print("Hạn ngạch tổ chức còn lại:", result["quota"]["remaining"])

2. Mã phản hồi HTTP (Error Codes)

HTTP Code Trạng thái Nguyên nhân Trừ Quota?
200 OK Chẩn đoán thành công Ảnh đạt tiêu chuẩn lá cây và mô hình hoàn thành phân loại. Có (-1 lượt)
422 Unprocessable Ảnh bị từ chối Ảnh không phải lá cây (NOT_A_LEAF) hoặc mờ nhòe. Không trừ
401 Unauthorized Không có quyền API Key không hợp lệ hoặc đã bị thu hồi. Không trừ
403 Forbidden Vượt gói dịch vụ Gọi mô hình VIP khi tổ chức chưa kích hoạt gói Team/Enterprise. Không trừ
429 Too Many Requests Hết hạn ngạch Tổ chức đã dùng hết số lượt quét trong chu kỳ 24 giờ. Không trừ
